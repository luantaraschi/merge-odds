# Support

Use [Q&A](https://github.com/luantaraschi/merge-odds/discussions/categories/q-a) for help with measurement, evidence, schema fields, or the site. Link the entry or issue you are reading and say which part is unclear.

Use the measurement form to request a project and the dispute form to correct a published claim. Security problems belong in the private vulnerability form described in `SECURITY.md`.

This project does not provide private consulting about whether a particular pull request will be accepted.
