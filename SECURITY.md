# Security

Report a vulnerability through [GitHub's private vulnerability form](https://github.com/luantaraschi/merge-odds/security/advisories/new). Do not open a public issue for an exposed credential, unsafe API handling, workflow permission problem, or exploit in the generated site.

Include the affected commit, the smallest reproduction you can provide safely, and the impact you observed. The current `main` branch is supported.

Incorrect or stale dataset claims are not security reports. Use the dispute issue form for those.
